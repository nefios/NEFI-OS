# Security Policy

NEFI OS is a defensive security distribution, so we take vulnerabilities in it seriously.

## Reporting a vulnerability

**Please do not open a public issue.** Use GitHub's private reporting instead:
**Security** tab → **Report a vulnerability**.

Include what is affected (module, script, package), how to reproduce it and the impact.
We aim to acknowledge reports within 7 days and to publish a fix in the next release.

## Supported versions

Only the latest release receives security fixes. NEFI OS is based on Debian 13 "trixie":
Debian security updates are installed automatically on every NEFI OS system.
